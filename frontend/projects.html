safepip

A security wrapper around pip install that helps ensure you're installing the package you actually intend to install. Defends against typosquatting — where malicious packages use names that resemble popular ones with a small typo.

  • Levenshtein distance check against the top 1,000 PyPI packages
  • Displays PyPI metadata: summary, author, creation date, last update
  • Pulls GitHub stats (stars, forks, open issues) when a repo is linked
  • Prompts for confirmation, then runs the real pip install

SnapHealth

Anthropic Claude Builder Club Hackathon — Spring 2026. Built with Roshan Tailor and Frederick Rajakumar.

An AI-powered health literacy and triage tool for people without easy access to medical guidance. Users can describe symptoms in plain text, upload a photo of a wound or skin condition, or point their camera at a medication label and receive a clear, structured assessment in plain English. It doesn't replace a doctor — it helps people understand what they're looking at well enough to take the right next step.

Book Recommender

An AI-powered book recommendation engine integrated into this site. Uses Ollama (Mistral 7B) to extract search keywords from natural language queries, retrieves up to 10,000 candidates from OpenLibrary, narrows them to 200 with a custom C++ Vamana approximate nearest-neighbor index, then reranks using sentence-transformer embeddings.

MIT 6.1810 — xv6 Labs

Self-study work through MIT's operating systems course (6.1810, fall 2024 materials). xv6 is a small Unix-like teaching kernel written in C and ported to RISC-V. Labs completed: utilities, syscall, page tables, traps, copy-on-write fork, user-level threads, network stack driver, fine-grained locking, large files & symlinks, and memory-mapped files.
